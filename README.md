## 安装及升级 OpenWrt 的相关说明


- ### 磊科 N60PRO
  关机长按reset键5秒,`千兆Lan  (不要使用2.5G lan)`  口连接电脑 → 浏览器输入`192.168.1.1` 进入uboot → 上传固件刷入等待重启即可
